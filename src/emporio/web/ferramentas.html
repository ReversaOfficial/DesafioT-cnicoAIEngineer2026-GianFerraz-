Por que esta página existe. A tese do projeto é que o LLM decide o que perguntar e como conversar, mas preço, prazo, frete e disponibilidade saem de código Python testado. Aqui esse código roda sozinho: nenhuma chamada de modelo, nenhuma chave de API, nenhuma cota. Esta parte do serviço nunca fica indisponível — e é a mesma camada que o agente consulta ao conversar.
